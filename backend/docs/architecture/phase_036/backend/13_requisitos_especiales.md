# Requisitos especiales

Los requisitos especiales se capturan como códigos controlados en el aviso y se congelan en la revisión/cita. Sirven para planificación y advertencias, no para asignar muelle ni iniciar tareas físicas.

Ejemplos admitidos por contrato incluyen cadena de frío, mercancía peligrosa, manipulación especial y seguridad reforzada. La interpretación operativa pertenece a fases posteriores.
