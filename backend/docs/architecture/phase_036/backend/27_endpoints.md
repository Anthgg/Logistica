# Endpoints

Prefijo: `/api/logistics`.

- Avisos: CRUD/listado, copy, revisiones, líneas, vehículo, conductor, documentos, validate, submit, transiciones, cancel y capabilities.
- Calendarios: CRUD/estado, operating windows, blackouts y availability.
- Holds: create, read, cancel y refresh.
- Citas: create/list/read, validate, confirm, request-reschedule, reschedule, cancel, history, capabilities y gate-preparation.
- CIT: preview, issue y document.
- Paquetes: request, status y download.

OpenAPI expone 33 operaciones de avisos, revisiones, líneas, referencias de transporte y documentos, además de 33 operaciones de calendarios, holds, citas y paquetes. No existen rutas de check-in, muelle, descarga o recepción física.
