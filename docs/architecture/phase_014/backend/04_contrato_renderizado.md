# 04 — Contrato de Renderizado

## Objetos de Transferencia
- `DocumentRenderCommand`: Contiene metadatos del documento, título, organización, datos de ítems y configuraciones de marca de agua/QR.
- `HtmlRenderResult`: Resultado de renderizado HTML procesado con hash SHA-256.
- `PdfRenderResult`: Contenido binario PDF con hash SHA-256, tiempo de renderizado y sugerencia de nombre de archivo.
