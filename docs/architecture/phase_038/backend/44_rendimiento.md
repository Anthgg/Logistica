# 44. Rendimiento

Índices cubren organización/almacén/estado, prioridad/tiempo, Gate, dock/estado, operación, pausas, eventos y jobs. Las listas deben paginarse en volúmenes altos; las decisiones de asignación bloquean únicamente filas relevantes.

Medir p95 de plan y confirmación, contención de locks, backlog de outbox, proyección atrasada y scans secuenciales antes de ajustar índices.
