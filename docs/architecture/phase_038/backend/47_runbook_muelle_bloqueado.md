# 47. Runbook: muelle bloqueado

1. Identificar maestro, blackout y asignaciones impactadas.
2. No inactivar con asignaciones activas.
3. Solicitar reasignación antes de descarga; generar plan y confirmar hash nuevo.
4. Si la descarga inició, pausar/abortar según seguridad operacional.
5. Desbloquear con permiso crítico, step-up y motivo.
