# 46. Runbook: descarga abandonada

1. Revisar alerta `UnloadingOperationAbandoned`, estado, pausas y responsables.
2. Confirmar físicamente la situación sin modificar tiempos manualmente.
3. Reanudar o abortar mediante comando autorizado y step-up.
4. Liberar el muelle solo después de completar/abortar.
5. Solicitar corrección auditada si existe error temporal; nunca sobrescribir fuente.
