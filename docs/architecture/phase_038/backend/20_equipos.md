# 20. Equipos

`unloading_equipment_assignments` permite asociar tipo, fuente, referencia e identificador snapshot sin asumir que existe un catálogo maestro. La disponibilidad requerida continúa siendo un check de readiness bloqueante.

Asignar equipo no crea activos, mantenimiento ni inventario. El catálogo maestro de equipos queda como decisión externa futura.
