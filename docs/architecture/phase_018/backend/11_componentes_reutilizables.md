# Componentes Reutilizables (Phase 018)

## Lista de Componentes
1. **destination_information.html**: Muestra el destino enmascarado y los datos del contacto de entrega.
2. **outbound_items_table.html**: Tabla compacta para SKU, descripción y cantidades autorizadas.
3. **stock_allocation_summary.html**: Visualización de stock reservado.
4. **picking_route_summary.html**: Ruta secuencial ordenada por pasillos y niveles.
5. **picking_progress.html**: Barra y kpi de progreso de recolección.
6. **package_hierarchy.html**: Representación de árbol para cajas y pallets.
7. **vehicle_information.html**: Patente y detalles del camión.
8. **driver_information.html**: Conductor con DNI/licencia enmascarados.
9. **loading_summary.html**: Unidades y pesos esperados vs cargados.
10. **capacity_validation.html**: Alertas de exceso de carga del vehículo.
