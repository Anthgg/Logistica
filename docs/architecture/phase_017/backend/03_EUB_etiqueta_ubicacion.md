# EUB — Etiqueta de Ubicación (Phase 017)

## Propósito
Identificación visual e inequívoca de las ubicaciones físicas en el almacén.

## Formatos de Impresión
Diseñado para admitir múltiples formatos físicos:
- **A6 (Predeterminado)**: Optimizado para impresión térmica directa de etiquetas (100x150mm).
- **A5**: Para señalización de racks de nivel superior.
- **A4 (Planillas)**: Soporte proyectado para impresión masiva.

## Elementos Clave
- **Código de Ubicación Grande**: Tipografía de 22pt para lectura a distancia.
- **Jerarquía de Espacios**: Desglose visual de Zona, Pasillo, Estante, Nivel y Posición.
- **Estado de Ubicación**: Badge de estado (`ACTIVE`, `BLOCKED`, `MAINTENANCE`).
- **QR de Demostración**: Código QR con el string de ubicación para pruebas de escaneo (no productivo).
