# Componentes Reutilizables de Inventario (Phase 017)

## Fragmentos HTML Especializados
Para asegurar la consistencia del diseño de la familia **INVENTORY**, se implementaron componentes CSS/HTML modulares:
1. `location_information.html` — Muestra el desglose físico de ubicaciones.
2. `product_information.html` — Ficha de SKU, descripción y metadatos.
3. `stock_state_breakdown.html` — Detalle del estado físico y de calidad del inventario.
4. `lot_serial_information.html` — Control de lotes, series y vencimientos.
5. `quantity_comparison.html` — Grilla comparativa de cantidades despachadas vs aceptadas.
6. `adjustment_reason.html` — Desglose de motivos de ajuste y causas raíz.
7. `count_team.html` — Tabla del equipo de conteo.
8. `approval_chain.html` — Bloques visuales para firmas de solicitudes y aprobaciones.
9. `transfer_route.html` — Gráfico de flujo origen → destino.
10. `transfer_timeline.html` — Hitos temporales de la transferencia.
11. `evidence_references.html` — Listado de actas o fotos de respaldo.
12. `QR_label.html` — Renderizador del código QR de previsualización.
