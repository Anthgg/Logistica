# ADI — Acta de Diferencia de Inventario (Phase 017)

## Propósito
Documentar e iniciar el proceso de investigación de las diferencias detectadas durante un conteo físico.

## Clasificación de Diferencias
Cada línea con discrepancia se categoriza visualmente con badges específicos:
- `SHORTAGE` (Faltante)
- `OVERAGE` (Sobrante)
- `WRONG_LOCATION` (Ubicación incorrecta)
- `DAMAGED` (Mercadería dañada)
- `UNKNOWN_CAUSE` (Causa desconocida)

## Proceso de Investigación
Permite registrar la causa probable analizada por el equipo de control de inventarios, la recomendación de disposición final y el ajuste propuesto (AJI derivado).
