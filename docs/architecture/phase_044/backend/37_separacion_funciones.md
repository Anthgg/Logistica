# 37 — Separación de funciones

- El solicitante de compensación no puede ser el aprobador.
- El aprobador no puede ejecutar (debe ser un actor separado).
- Quien aprueba no debe alterar la solicitud.
- Quien publica eventos no aprueba compensaciones.
- Un administrador técnico no obtiene permiso operativo automáticamente.
- Exportaciones sensibles requieren alcance.
- Reconciliación no modifica movimientos.
- La compensación deja evidencia de revisión.
