# 06 — Familias y tipos de movimiento

## Familias

- `INBOUND`
- `OUTBOUND`
- `INTERNAL_TRANSFER`
- `AVAILABILITY_TRANSITION`
- `QUALITY_TRANSITION`
- `RESERVATION`
- `ADJUSTMENT`
- `COUNT_VARIANCE`
- `WAREHOUSE_TRANSFER`
- `RETURN`
- `COMPENSATION`
- `MIGRATION`
- `SYSTEM_CORRECTION`

## Tipos (extracto)

Ingresos: `INBOUND_RECEIPT_RECOGNIZED`, `QUARANTINE_ENTRY`,
`QUALITY_RELEASE_TO_STAGING`, `PUTAWAY_COMPLETED`, `TRANSFER_RECEIPT_FUTURE`,
`CUSTOMER_RETURN_RECEIPT_FUTURE`, `MIGRATION_OPENING_ENTRY`.

Salidas: `OUTBOUND_PICK_ISSUE_FUTURE`, `OUTBOUND_DISPATCH_FUTURE`,
`TRANSFER_DISPATCH_FUTURE`, `SUPPLIER_RETURN_FUTURE`,
`DESTRUCTION_FUTURE`, `MIGRATION_OPENING_EXIT`.

Traslados: `LOCATION_TRANSFER`, `STAGING_TO_STORAGE`,
`STORAGE_TO_STAGING_FUTURE`, `WAREHOUSE_TRANSFER_IN_TRANSIT_FUTURE`.

Reservas: `RESERVATION_CREATED`, `RESERVATION_RELEASED`,
`RESERVATION_CONSUMED`, `RESERVATION_EXPIRED`.

Calidad/estado: `QUARANTINE_APPLIED`, `QUARANTINE_RELEASED`,
`QUALITY_BLOCKED`, `QUALITY_APPROVED`, `DAMAGED_APPLIED`,
`DAMAGED_RELEASED`, `EXPIRED_APPLIED`, `EXPIRATION_CORRECTED`,
`TRANSIT_APPLIED`, `TRANSIT_RELEASED`.

Ajustes futuros: `ADJUSTMENT_INCREASE_FUTURE`,
`ADJUSTMENT_DECREASE_FUTURE`, `COUNT_VARIANCE_INCREASE_FUTURE`,
`COUNT_VARIANCE_DECREASE_FUTURE`.

Correcciones: `TECHNICAL_COMPENSATION`,
`SOURCE_EVENT_REPLAY_CORRECTION`, `MIGRATION_CORRECTION`.

Los tipos `*_FUTURE` están deshabilitados (no se pueden publicar).
