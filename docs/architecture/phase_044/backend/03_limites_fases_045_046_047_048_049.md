# 03 — Límites hacia fases 045, 046, 047, 048, 049

## Fase 045 — Saldos

- **No implementada**.
- Se entrega: `InventoryBalancePreparationService` que expone entradas
  inmutables, una por línea, con `entry_base_quantity`, `exit_base_quantity`,
  `signed_delta_for_position`, `balance_materialization_key`.
- La Fase 045 consumirá este servicio como **única fuente** para construir
  la tabla de saldos.

## Fase 046 — Trazabilidad

- **No implementada**.
- Se entrega: `InventoryTraceabilityPreparationService` con observaciones
  de lote/serie/vencimiento/packaging.
- La Fase 046 materializará las entidades `lot_master` y `serial_master`.

## Fase 047 — Ajustes

- **No implementada**.
- Adaptadores `ADJUSTMENT_APPROVED`, `PHYSICAL_COUNT_VARIANCE_APPROVED`
  registrados pero **habilitados = False**.
- Los tipos `ADJUSTMENT_INCREASE_FUTURE`, `ADJUSTMENT_DECREASE_FUTURE`,
  `COUNT_VARIANCE_INCREASE_FUTURE`, `COUNT_VARIANCE_DECREASE_FUTURE`
  declarados pero **disabled**.

## Fase 048 — Conteos físicos

- **No implementada**.
- Solo se materializa el contrato: el adaptador
  `PHYSICAL_COUNT_VARIANCE_APPROVED` está documentado.

## Fase 049 / 050 — Transferencias

- **No implementada**.
- Tipos `TRANSFER_DISPATCH_FUTURE`, `TRANSFER_RECEIPT_FUTURE`,
  `WAREHOUSE_TRANSFER_IN_TRANSIT_FUTURE` declarados pero **disabled**.
