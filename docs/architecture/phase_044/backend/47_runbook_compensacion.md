# 47 — Runbook: compensación

## Procedimiento

1. Investigador abre `compensation_request` con evidencia.
2. Revisor verifica la legitimidad.
3. Aprobador (CRITICAL step-up) aprueba.
4. Ejecutor (CRITICAL step-up) ejecuta.
5. Verificar que el original sigue en la tabla.
6. Verificar que la compensación tiene código MOV nuevo.
7. Auditar.
