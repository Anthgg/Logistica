# 16. Catálogo de Auditoría

Códigos de auditoría específicos de ciclo documental registrados en el catálogo central de la Fase 020:

- **logistics.document.draft_created**: Borrador de documento creado.
- **logistics.document.draft_updated**: Borrador de documento actualizado.
- **logistics.document.preview_rendered**: Vista previa de PDF renderizada.
- **logistics.document.issued**: Documento oficial emitido con correlativo.
- **logistics.document.print_requested**: Intención de impresión física registrada.
- **logistics.document.reprinted**: Copia física oficial de reimpresión generada.
- **logistics.document.cancelled**: Documento anulado con marca visual.
- **logistics.document.original_accessed**: Descarga del PDF original de un anulado.
- **logistics.document.integrity_failure**: Alerta crítica de discordancia de hash binario.
