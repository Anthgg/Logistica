# 11 — Políticas de Retención Documental

## Clases de Retención Registradas

| Código de Política | Clase | Días Mínimos de Conservación | Revisión Manual |
| :--- | :--- | :--- | :--- |
| `RET_OPERATIONAL_STANDARD` | `OPERATIONAL_STANDARD` | 365 días (1 año) | `True` |
| `RET_LEGAL_COMMERCIAL` | `COMMERCIAL` | 1825 días (5 años) | `True` |

## Regla Estricta
No se implementa eliminación automática de documentos. La depuración de datos requiere aprobación explícita de negocio.
