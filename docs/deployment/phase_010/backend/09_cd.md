# 09 — Pipeline de Entrega Continua (CD)

## Workflow de CD (`.github/workflows/cd.yml`)

1. **Despliegue a Staging:**
   * Despliegue automático tras integrar código en la rama `develop`.
   * Generación y etiquetado de la imagen inmutable (`api:sha-abc123`).
   * Ejecución de job de migración de esquema.
   * Actualización del servicio `proyecto-t1-api-staging`.

2. **Despliegue a Producción (Con Aprobación Manual):**
   * Despliegue protegido con entorno de aprobación obligatoria (`production`).
   * Verificación previa de respaldo de base de datos.
   * Ejecución de job de migración Out-of-band.
   * Despliegue de la revisión en Cloud Run (`autenticacion-continua-api`).
   * Asignación progresiva de tráfico (100% una vez validados los smoke tests).
