# 08 — Pipeline de Integración Continua (CI)

## Workflow de CI (`.github/workflows/ci.yml`)
El flujo de integración continua se activa ante cada `push` o `pull_request` sobre las ramas `main` y `develop`:

1. **Checkout & Cache:** Checkout del código y configuración de Python 3.11 con caché de dependencias pip.
2. **Linter & Formato:** Ejecución de `ruff check .`.
3. **Comprobación de Tipos:** Verificación mediante `mypy app`.
4. **Pruebas Automatizadas:** Ejecución del conjunto de pruebas Pytest (`pytest -m "not ml"`).
5. **Validación OpenAPI:** Garantía de que la especificación OpenAPI de FastAPI se genera sin errores.
6. **Construcción de Imagen Docker:** Prueba de construcción de la imagen (`docker build`) sin subir al registry.
